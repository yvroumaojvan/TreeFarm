==================================================
🌳 TreeFarm · 树场机制
用耦合基因库给 AI 省 token 的代码分析引擎
==================================================

【一句话】
让 AI 读大项目时——只读该读的、读一遍就记住、
验证过才相信。

【治什么痛点】
AI 读大仓库的四大浪费：
  ① 读了一堆用不上的配置/资源
  ② 该读的反复重读
  ③ 读了和任务无关的文件
  ④ 代码之间的依赖全靠猜

【森林比喻（核心机制）】
  代码仓库 = 树场
  ├── 杂草     配置/资源 → 只存摘要，命中才展开
  ├── 大树     核心代码 → 按任务挑重点读
  ├── 参天大树 耦合基因库 → 已验证的依赖关系，持久化复用
  ├── 小鸟     AI 发现可疑耦合 → 报上去验证
  ├── 小虫子   静态分析工具 → 0 token 验证基因真假
  └── 垃圾箱   熔断器 → AI 反复失误的区域先隔离、最后专项修

★ 实测战绩（真实数据，非估算）
==================================================

真实 APK（21MB / 9187 个 Java 文件）：
  全量傻读 1232.6 万 tokens
  → 树场简报 26.2 万 tokens
  → 省 97.9% ★

  基因库 57919 条，建库仅 2 分钟
  语义搜索「accessibility」5 秒直达核心文件

规模模拟：50 文件省 95.6% / 100 文件省 96.3% / 500+ 省 96.9%

（诚实边界：8 小文件小项目实测反亏 112.8%
  ——小项目/一次性任务请直接读，别开树场）
