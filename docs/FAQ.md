# ❓ TreeFarm 常见问题（FAQ）

## 安装与运行

### Q: 要装什么依赖吗？
A: 零依赖。只需 Python 3.8+（标准库即可）。`pip install` 都不需要。
flake8 / pytest 只在开发/CI 用，用户不需要装。

### Q: 在 Termux / 服务器 / CI 能跑吗？
A: 能。纯标准库 = 任何有 Python 的环境都能跑（旧电脑、容器、CI runner）。

### Q: `python3 tree_farm.py <项目>` 报错"项目不是目录"？
A: 第一个参数必须是项目根目录路径。相对/绝对路径都支持。

## 用法

### Q: 小项目值得用吗？
A: 几个小文件直接读更划算（简报开销 > 直接读）。树场为「大项目 + 多轮排查」设计。

### Q: `--repl` 里怎么退出？
A: 输入 `exit` / `quit`，或 Ctrl+D / Ctrl+C。

### Q: REPL 的 Tab 补全没反应？
A: 需要 readline（CPython 默认自带）。如果终端不支持，会自动降级为无补全模式，
不影响其他功能。

### Q: 中文命令怎么用？
A: `python3 tree_farm.py <项目> 分析 死代码` / `分析 异味` / `分析 影响 <文件>` 等。

### Q: `--json` 支持哪些命令？
A: 默认体检、`--brief`、`--graph`（结构化调用图）。其他命令正在逐步扩展。

## 数据与存储

### Q: 基因库存哪？
A: `<项目>/.tree_farm/treefarm.db`（SQLite，WAL 模式，原子事务）。
`.gitignore` 已排除 `.tree_farm/`，不会入库。

### Q: 怎么重建基因库？
A: 删除 `.tree_farm/` 目录后重跑任意命令，自动重建。

### Q: 增量扫描的原理？
A: mtime + 文件大小 + 内容指纹三级判断。没变的文件不重新提取，只重扫变更文件。

### Q: 换目录/重命名项目会怎样？
A: 重命名检测会自动迁移基因；删文件会级联回收相关基因。

## 分析准确度

### Q: 死代码/异味检测会误报吗？
A: 会。Python 走 AST 较准；JS/Java/Go/Rust 是轻量启发式，**需人工确认后再删/改**。
入口函数、被反射/字符串调用的符号可能被误判为死代码。

### Q: 为什么 Rust 的 trait 继承有些没报？
A: 标准库 trait（Send/Sync/Clone/Debug 等）自动过滤——项目里没有它们的定义，
入库是纯噪音。只报项目内定义的 trait 继承。

### Q: 魔法数字为什么有些没报？
A: 排除表：0/1/2/3/-1/0.0/1.0/0.5/100/1000 等常见数字；`range(10)` 的参数；
测试文件（`test_*`、`*_test.*`、`/tests/`）。这些都是正常用法，不报。

### Q: 影响分析跨语言吗？
A: 跨语言。函数级 call 基因对 Python/JS/Java/Go/Rust 都入库，改任意语言文件
都能列出全部跨语言调用方（v3.6 测试锁定）。

## LLM 功能

### Q: `--analyze` 没反应/提示 dry-run？
A: 没配 API key。配置 `.treefarm.json`（项目目录或 `~`）或环境变量
（`TREEFARM_API_KEY` / `OPENAI_API_KEY` / `DASHSCOPE_API_KEY` / `DEEPSEEK_API_KEY` 等）。

### Q: 怎么省钱？
A: 先 `--brief` + `--genes` 定向看，别 `--analyze` 全量；报小鸟只对重点文件。
LLM 功能默认开启但只在 `--analyze` 时真正调 API。

### Q: 关闭 LLM？
A: `--llm off`（或对 AI 说「关闭 LLM」），`--llm on` 恢复，`--llm status` 查看。

## 性能

### Q: 大项目慢吗？
A: 1000 文件首次扫描实测 ~2s、峰值内存 ~40MB；增量 <0.5s。比预估值快 18 倍。
如果还很慢，先配 `scan.ignore` 排除无关目录。

### Q: 查重在大项目会卡吗？
A: 函数级查重按函数体大小分桶（size//64），1000 文件约 1.2s。

## 兼容与版本

### Q: 旧版基因库要重建吗？
A: 不需要。schema 升级时自动全量重扫一次补齐新类型基因（如 v2→v3 的函数级基因）。

### Q: 支持哪些语言？
A: Python / JS / TS / Java / Go / Rust 六种有函数级分析；C/C++ 等有 import 级。
Rust 支持（v3.7）：函数/方法/泛型/生命周期/unsafe/async/trait 继承。

### Q: 和思维树什么关系？
A: 树场是「上下文引擎」（发现问题），思维树是「决策引擎」（解决问题）。
两级触发链：说「开启思维树」只开思维树；再说「开启深度思考模式」树场才启动。
