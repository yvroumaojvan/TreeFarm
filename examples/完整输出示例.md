# 完整输出示例

本文展示思维树通用版的实际输出效果（**默认配置：8 分支 × 3 轮**）。
示例问题：**「该不该辞职去创业？」**

> 以下输出均由 `scripts/render-tree.js --demo` 实测生成（Node v26.4.0）。

---

## 〇、先看懂"真思考"长什么样（重要！）

思维树的价值在于**真 AI 思考**，而不是套模板。同一个问题，对比一下：

| | ❌ 模板垃圾（禁止！） | ✅ 真 AI 思考 |
|---|---|---|
| 分支维度 | 技术可行性 / 成本效益 / 用户体验（任何问题都能套） | 财务安全边际 / 市场验证信号 / 行业周期 / 竞争者格局…（只属于"辞职创业"） |
| 推理内容 | "技术层面可行""有成本优势"（空话） | "创业回本周期 9~18 个月，6 个月存款覆盖不了"（具体数字+机制） |
| 结论 | "整体可行，建议推进"（万金油） | "先拿到 3~5 个付费订单，再考虑全职投入"（可执行、有标准） |

**自查方法**：把分支维度拿去套别的领域——套得上就是模板，必须重做。

```
    │   ├── 🌿 兼职过渡排期

    │   │       推理 → 每周 20 小时接单 + 固定创业时段，排期必须错峰
    │   │       结论 → 固定"创业时段"，防止两头都做不好

    │   ├── 🌿 时间管理

    │   │       推理 → 番茄钟 + 任务看板，每天固定 3 小时深度工作

    │   ├── 🌿 风险准备金
    │   │       假设 → 最坏情况可控
    │   │       推理 → 预留 6 个月生活备用金，不动用股市资金和借款

    │   ├── 🌿 家庭沟通节点

    │   │       推理 → 每月一次进度同步，用数据说话比情绪说服有效

    │   ├── 🌿 退出条件复盘
    │   │       假设 → 失败可以优雅退出
    │   │       推理 → 第 3 个月末按数据做"继续/全职/止损"三选一
    │   │       结论 → 决策日设为第 90 天
    │   └── 🧡 第 3 轮共识
    │           共识 → 3 个月验证期目标清晰：转化率 2% + 首单 + 定价数据齐备，第 90 天做最终决策
    └── 💎 最终答案
            结论先行：现在不该直接辞职。用 90 天做最小验证：2 周 MVP 挂 3 个平台测转化率，30 天内拿下首单，同时攒够 18 个月缓冲金，第 90 天按数据做全职决定。

            风险与不确定性：行业下行期转化率可能低于预期，需要 2% 转化率硬指标把关。
            行动建议：本月启动 MVP + 3 平台测转化，固定每天 3 小时深度工作，第 30 天复盘首单进度。
            📋 推理摘要 → 三轮推理从财务、市场、能力、家庭、行业、竞争、健康、合规八个维度展开，第 2 轮聚焦验证路径，第 3 轮细化为可执行的 90 天计划；弱信号（社保断缴风险）跨轮被验证为真信号。
            ⏹ 停止原因 → 达到最大轮数
```

**🌟 本示例的看点**：
- **24 个分支全跑满**（8×3），停止原因"达到最大轮数"——不偷懒提前收敛
- **弱信号跨轮验证**（你的原创机制的完美示范）：社保断缴风险在第 1 轮被 1/8 分支提出 ⚡ → 第 2 轮再次出现 ⚡ → 最终答案采纳为"过渡期需主动续缴"。从"被忽略的要点"成长为"落地行动"
- 三轮递进：第 1 轮找维度 → 第 2 轮定路径 → 第 3 轮排执行计划（90 天计划），思考越来越具体
